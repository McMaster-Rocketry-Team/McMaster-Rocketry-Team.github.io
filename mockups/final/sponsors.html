Build the next one

We hire first years.

We hire people who have never touched a rocket. The only thing we ask is that you want to find out how high this one goes.

Applications open at the start of each term and we run an info session in the first two weeks. You do not need to be an engineer — we need people on business, outreach and finance as much as on airframe.
